## Homework Assignment — Reading and Review, Plus the Final-Project Presentation Outline

Training 27 (Mon Oct 19, 2026). Teacher: Evan Flint.

**Details from class notes only.** Evan gave this homework verbally; no written prompt was handed out.

### What Evan assigned

> "I'm giving you both some reading and review to do plus an outline of what we're going to be doing for the actual presentations."

From the start of class:

1. **Propose an original pipeline concept**: "some kind of original concept for a pipeline."
2. **Tell Evan whether you have PowerPoint or another slideshow tool**: "it doesn't particularly matter to me, just as long as it's some sort of presentation tool."
3. **Reading and review** of the day's material (no specific reading list was given). Today's topics: Blob Storage vs ADLS Gen2 and the hierarchical namespace, Entra ID and managed identities, tenant vs subscription, Event Hubs, Azure Data Factory, Databricks and Delta Lake, open table formats, Unity Catalog, Synapse and Fabric.
4. **An outline of your final-project presentation.**

"What the management is going to want to see is both the pipeline itself and an accompanying presentation."

### Final-project presentation requirements (as stated in class)

| Requirement | What Evan said |
|---|---|
| Your own data | Not the Citi Bike data everyone already used. Find your own data source, investigate it, analyze it, and work out what code you'll need to process it |
| Platform | A pipeline on AWS or Azure, whichever is more convenient for your kind of data |
| Audience | Management, "who are not necessarily technical." Open with a **high concept** (example: weather patterns that could affect a company's shipments) |
| Style | "More of a research pitch rather than a developer pitch" |
| Core content | The pipeline itself: the **ingestion**, **processing** and **storage** stages, and the **analytics** that answer the main question |
| Architecture | A multi-layer data lakehouse: Bronze, Silver and Gold |
| Length | About 5 to 10 minutes (also said 8 to 10); longer is fine if it's good information |
| Date | Not set yet. "Probably in like five to seven working days." Evan will confirm |
