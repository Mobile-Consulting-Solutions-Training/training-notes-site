2. CTE — Order Totals
Create a CTE named order_totals that calculates the total value of each order using:

price × quantity

Return only orders whose total value is greater than 5,000, sorted from highest total to lowest.

```sql
WITH order_totals AS (
    SELECT 
    order_number,
        SUM(price * quantity) AS total_value
    FROM orderdetails
    GROUP BY order_number
)
SELECT order_number, total_value
FROM order_totals
WHERE total_value > 5000
ORDER BY total_value DESC;
```

>3. Create a CTE that calculates the total revenue generated by each product_number from orderdetails. Then join the CTE to products so the final result contains product_number, product_name, product_category, and total revenue. Sort from highest revenue to lowest.

```sql
WITH total_revenue AS (
    SELECT product_number, 
    SUM(price * quantity) AS total
    FROM orderdetails
    GROUP BY product_number
)
SELECT 
    x.product_number, 
    y.product_number,
    y.product_name,
    y.product_category,
    x.total
FROM total_revenue x
JOIN products y ON x.product_number = y.product_number
ORDER BY x.total DESC;
```

>4.  For every record in orderdetails, return product_number, product_category, and price, along with the average price for that product's category. Use AVG() as a window function with PARTITION BY. Do not use GROUP BY.

```sql
SELECT 
product_number,
product_category,
price,
AVG(price) OVER (PARTITION BY product_category) 
AS category_average
FROM orderdetails;
```

>5. Window Function — Ranking 
>Rank the products within each product_category according to price, with the highest price ranked first. Return product_number, product_category, price, and the rank. Use DENSE_RANK() so products with identical prices receive the same rank.

```sql
WITH ranked_products AS (
    SELECT
        product_number,
        product_category,
        price,
        DENSE_RANK() OVER (PARTITION BY product_category ORDER BY price DESC) AS price_rank
    FROM orderdetails
)
SELECT *
FROM ranked_products;
```

>6.CTE + Window Function — Top 3 per Category
>Find the three highest-priced records in each product category. Use a window function to assign the ranking and a CTE to allow you to filter the results. The final result should contain only ranks 1–3.

```sql
WITH ranked_products AS (
    SELECT
        product_number,
        product_category,
        price,
        DENSE_RANK() OVER (PARTITION BY product_category ORDER BY price DESC) AS price_rank
    FROM orderdetails
)
SELECT *
FROM ranked_products
WHERE price_rank < 4;
```
