| Piece | What to know |
|---|---|
| **Bronze** | Exactly what arrived, plus when and where it came from (`source_file`, `ingested_at`). Never edited, so mistakes downstream can be fixed by reprocessing |
| **Silver** | Casts, null and range checks, flattening nested JSON, dropping duplicates. One row per real-world event |
| **Gold** | Shaped for the questions: aggregates, a star schema of facts and dimensions, or ML features |
| **Why layers** | Each step is small and testable, and a bug in Gold never forces you to re-ingest from the source |

| Piece | What to know |
|---|---|
| **Identity** | ADF uses its managed identity with Storage Blob Data Contributor on the storage account; Databricks uses an Access Connector the same way |
| **Unity Catalog chain** | Access Connector → role on storage → storage credential → external location → external volume |
| **Databricks** | Auto Loader (`cloudFiles`) ingests only new files; notebooks explode the stations array, clean, and aggregate hourly; Delta gives MERGE and time travel |
| **Serving** | Synapse serverless SQL queries Silver Parquet with `OPENROWSET` views; Power BI connects to the `-ondemand` endpoint |
